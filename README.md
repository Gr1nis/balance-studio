# ⚔️ Balance & Progression Studio

> 🔗 **Живая опубликованная версия сервиса:** **[https://gr1nis.github.io/balance-studio/](https://gr1nis.github.io/balance-studio/)**  
> 📁 **GitHub Репозиторий проекта:** **[https://github.com/Gr1nis/balance-studio](https://github.com/Gr1nis/balance-studio)**

**Balance & Progression Studio** — интерактивное статическое веб-приложение для геймдизайнеров, предназначенное для настройки, анализа и аудита игрового баланса, расчёта боевых метрик (TTK / DPS), моделирования кривых прокачки и валидации вероятностей лута.

Сервис работает полностью локально без бэкенда и сервера, сохраняет состояние в `localStorage` и разворачивается в один клик на **GitHub Pages**, **Vercel** или **Netlify**.

---

## 🚀 Быстрый запуск

### Вариант 1: Запуск локально
1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone <url-вашего-репозитория>
   cd balance-studio
   ```
2. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Safari, Edge):
   * Двойным кликом по `index.html`, **или**
   * Через локальный веб-сервер (рекомендуется для загрузки модулей):
     ```bash
     npx serve .
     # или на Python:
     python3 -m http.server 8000
     ```
3. Откройте в браузере `http://localhost:8000`.

### Вариант 2: Публикация на GitHub Pages (Бесплатный хостинг)
1. Создайте публичный репозиторий на GitHub (например, `balance-studio`).
2. Запушьте код:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Balance & Progression Studio MVP"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/balance-studio.git
   git push -u origin main
   ```
3. В настройках репозитория перейдите в **Settings** → **Pages**:
   * В разделе **Build and deployment** выберите Source: `Deploy from a branch`.
   * Ветка: `main`, папка: `/ (root)`. Нажмите **Save**.
4. Через 1–2 минуты ссылка вида `https://<ваш-логин>.github.io/balance-studio/` станет активна!

## 🎮 Возможности и модули

### 1. 📥 Импорт и экспорт данных
* Поддержка **CSV** и **JSON**.
* Загрузка через проводник и **Drag & Drop** зону.
* **Строгая валидация:**
  * Проверка обязательных колонок (`id`, `name`, `hp`, `attack`, `defense`).
  * Проверка типов данных (нечисловые значения, отрицательные статы).
  * Детектор дублирующихся `id`.
  * Информативные сообщения об ошибках с указанием строк.
* Встроенные быстрые демо-пресеты в 1 клик (Юниты RPG, Оружие).
* Экспорт базы юнитов и предметов в CSV и JSON без потерь.

### 2. 📋 Редактор базы данных юнитов
* Табличное представление всех сущностей.
* **Inline-редактирование ячеек** на лету с валидацией числовых диапазонов.
* Добавление новых юнитов и удаление строк.
* Мгновенный поиск и фильтрация по имени или ID.
* Автосохранение всех правок в `localStorage`.

### 3. 🎯 Калькулятор урона и TTK (Time To Kill)
* Выбор пары «Атакующий» → «Защитник» из базы.
* Поддержка двух математических моделей брони:
  * **Линейная (Flat):** $\text{Урон} = \max(1, \text{Атака} \times \text{Elem} - \text{Защита})$
  * **Процентная (Diminishing Returns):** $\text{Урон} = \text{Атака} \times \text{Elem} \times \frac{100}{100 + \text{Защита}}$
* Учёт критического шанса, множителя крита и стихийного бонуса.
* Расчёт **TTK (секунды)**, количества необходимых ударов, среднего **DPS** и **Effective HP (EHP)**.
* Настройка тайминга первого удара (мгновенный $t=0.0$с или с задержкой цикла $t=1/\text{APS}$).
* Интерактивный пошаговый боевой лог раундов дуэли.

### 4. 📈 Моделирование кривой прогрессии
* Три типа формул опыта:
  * **Степенная / Квадратичная:** $\Delta XP(L) = \lfloor \text{Base} \times L^{\alpha} \rfloor$
  * **Линейная:** $\Delta XP(L) = \text{Base} \times L$
  * **Экспоненциальная:** $\Delta XP(L) = \lfloor \text{Base} \times \text{Growth}^{L - 1} \rfloor$
* Интерактивные слайдеры базового опыта, коэффициента крутизны и макс. уровня (до 60 ур.).
* Интерактивный двухкоординатный график **Chart.js** (Опыт на уровень $\Delta XP$ и Накопленный $XP_{total}$).
* Таблица уровней с оценкой игрового времени (пэйсинг). Экспорт таблицы прогрессии в CSV.

### 5. 🎲 Валидатор и симулятор лут-таблиц
* Редактор таблицы лута (вероятности, редкость, диапазоны дропа min/max).
* Живой контроль суммы:
  * Зелёный статус при строгих **100.00%**.
  * Предупреждение с точным расчётом дефицита или избытка процентов при отклонении.
* Кнопка **«⚖️ Нормализовать к 100%»** — автоматическое масштабирование весов дропа.
* **Симулятор Монте-Карло (100 / 1 000 / 10 000 бросков):**
  * Проверка генератора случайных чисел.
  * Сравнение теоретической вероятности и фактической частоты с выводом дельты ($\Delta$).
* Экспорт таблицы дропа в CSV.

### 6. ⚖️ Бонусный модуль: Баланс-Аудит
* Эвристическая оценка эффективности юнитов:
  * $\text{DPS} = \text{Attack} \times \text{APS}$
  * $\text{EHP} = \text{HP} \times (1 + \text{Defense} / 50)$
  * $\text{Combat Power} = \sqrt{\text{DPS} \times \text{EHP}}$
  * $\text{Efficiency} = \frac{\text{Combat Power}}{\text{Cost}}$
* Автоматическая классификация:
  * 🔥 **OP (>125%)** — доминирующий юнит (слишком силён для своей цены).
  * ⚖️ **Баланс (80–125%)** — адекватный баланс ценности и цены.
  * 📉 **Trash (<80%)** — слабый / переоценённый юнит.

## ⌨️ Горячие клавиши

* `1`–`6` — Быстрое переключение между вкладками:
  * `1` — Импорт
  * `2` — Таблица
  * `3` — Калькулятор TTK
  * `4` — Прогрессия
  * `5` — Таблицы лута
  * `6` — Баланс-аудит
* `Ctrl + S` / `Cmd + S` — Быстрый экспорт активной базы юнитов в CSV.
* `Esc` — Закрыть окно справки.

│   ├── weapons.csv         # Оружие (Damage, Speed, Crit Chance, Cost)
